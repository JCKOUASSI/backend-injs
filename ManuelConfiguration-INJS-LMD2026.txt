## 0. Resume executif
---------------------

But du manuel :
  Permettre a une personne technique qui decouvre le projet de configurer,
  lancer et verifier, de bout en bout, le cycle academique LMD d'une
  etudiante fictive « Awa KONE -- DONNEE DE DEMONSTRATION » :
  campagne -> candidature -> admission -> inscription administrative et
  pedagogique -> notes -> jury -> diplomation (documents + registre).

Etat constate du depot (verifie le 2026-10-05, non destructif) :
  - Monorepo a plat : backend/ (Django 5.1.4 + DRF 3.15.2, 20 apps),
    frontend/ (React 18.2 + Vite 7), qr_badge_mobile/ (Flutter),
    docs/, scripts/, arena/, docker/.
  - 250 migrations Django, toutes appliquees ([X], 0 x [ ]) sur la base
    locale injs_lmd_current (PostgreSQL 16.14 Homebrew, 127.0.0.1:5432).
  - Sante confirmee : GET http://127.0.0.1:8000/api/health/ -> {"status":"ok","database":"ok"} ;
    GET http://localhost:3000/ -> 200.
  - `python manage.py check` : 1 warning urls.W005 (namespace dashboard_api
    non unique), 0 erreur.
  - Ports figes projet : API Django 8000, front Vite 3000 (strictPort:true),
    Postgres 5432 (local INJS-LMD) vs 5436 (Docker, autre instance).
  - Authentification JWT (SimpleJWT 5.4.0) + 12 roles canoniques
    (backend/authentication/models.py, classe User.Role).
  - Modules metier LMD presents et routés : admissions, scolarite,
    evaluations (suiviEvaluation + evaluations), jurys, graduation,
    finances_etudiantes, referentiels, parametres, edts, stages.
  - Script E2E de reference (non execute ici) :
    backend/tests_e2e_injs_2026_2027.py (parcours complet + 12 cas negatifs).
  - seed_data.py historique SYGEP-CPFAE avec mots de passe en clair :
    NE PAS utiliser tel quel en demo/prod (voir section 9).

Demarrage rapide (chemins confirmes) :
  [code]
  # Terminal 1 -- API (depuis racine du depot)
  cd backend && python3 manage.py check
  python3 manage.py showmigrations | grep -c "[X]"   # attendu : 250
  curl -s http://127.0.0.1:8000/api/health/
  # Lancement local fige (voir section 4 pour le choix du lanceur) :
  #   API : http://127.0.0.1:8000   Front : http://localhost:3000

## 6. Procedure de demonstration metier P1 (check-list numerotee)
----------------------------------------------------------------------

Format : Role | Action (ecran/API/commande) | Donnees demo | Resultat attendu | Preuve.
Si une etape etait indisponible, la mention exacte serait
« Non disponible dans le depot inspecte ». Ici toutes les etapes sont disponibles.

1. Ouverture campagne + referentiel. Role : demo.admin / demo.admission.
   Action : Scolarite -> Maquettes (creer/valider/activer DEMO-MAQUETTE) ;
   Campagnes (creer DEMO-CAMPAGNE-STAPS-2026, transition OUVERTE).
   API : POST /api/scolarite/maquettes/creer/, /<pk>/valider/, /<pk>/activer/ ;
   POST /api/admissions/campagnes/, /<pk>/transition/ {"statut":"OUVERTE"}.
   Attendu : maquette ACTIVE + campagne OUVERTE. Preuve : captures statuts.

2. Candidature d'Awa KONE. Role : demo.scolarite (ou auto-candidature si ouverte).
   Action : Candidatures (creer candidat KONE Awa + candidature DEMO-CAND-2026-001,
   deposer 4 pieces factices, SOUMETTRE).
   API : POST /api/admissions/candidats/, /candidatures/, /pieces/<id>/deposer/,
   /candidatures/<pk>/transition/ {"statut":"SOUMISE"}.
   Attendu : statut SOUMISE, numero genere. Preuve : fiche candidature + pieces.

3. Verification + admission. Role : demo.admission.
   Action : Controle des dossiers (verifier pieces -> PIECES_VALIDEES),
   passer EN_ETUDE -> ADMISSIBLE, creer Admission ADMIS (ref DEMO-ADM-2026-001).
   API : /pieces/<id>/verifier/, /candidatures/<pk>/transition/,
   POST /api/admissions/admissions/ + /<pk>/decision/ {"decision":"ADMIS"}.
   Attendu : Admission ADMIS, permet_inscription=true. Preuve : fiche admission.

4. Activation etudiant + matricule. Role : demo.scolarite.
   Action : Inscriptions -> inscrire_depuis_admission (ADMIS -> DossierEtudiant
   INJS26-DEMO-0001 + compte awa.kone AUDITEUR).
   API : POST /api/scolarite/inscriptions/depuis-admission/ {"admission":<id>}.

   Attendu : notes historisees (EvaluationGradeHistory). Preuve : listes notes.
