### 7.2 Défaut de la regex prescrite — `CONTRA-A410-01`

La regex prescrite par le mandat, `[A-Z]{3}8[0-9]{2}[0-9]{2}`, attend **8 caractères**.
Le format réel observé dans S-16 est **7 caractères** : `[A-Z]{3}8[0-9]{3}`.

```
BIO8101   →  B I O 8 1 0 1   = 7 caractères
regex     →  3 lettres + '8' + 4 chiffres attendus   = 8 caractères
résultat  →  0 correspondance  =  FAUX NÉGATIF TOTAL
```

**Arbitrage** : le format réel `[A-Z]{3}8[0-9]{3}` est retenu ; la regex de mission est déclarée
**défectueuse** et n'a pas été utilisée telle quelle. Voir `CONTRA-A410-01` (§19).
