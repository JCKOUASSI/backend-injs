SECTION 7 : CORRECTION DU BOUTON DE MASQUAGE DE LA BARRE LATÉRALE (SIDEBAR)
====================================================================================================
7.1 Diagnostic du Problème :
    * Le bouton `.sidebar-hide-toggle` situé dans l'en-tête de la barre latérale n'invoquait qu'une fermeture
      sur mobile sans basculer l'état `sidebarCollapsed` sur les résolutions bureau.
    * Incompatibilité de point de rupture (breakpoint) entre le CSS (768px vs 992px) et les gestionnaires d'état.
    * Manque d'accessibilité sur le bouton de bascule de la barre supérieure.

7.2 Solutions Implémentées :
    * `frontend/src/components/layout/Layout.jsx` :
      - Gestion bidirectionnelle de l'état : `sidebarCollapsed` (bureau) et `sidebarOpen` (mobile).
      - Détection réactive de la largeur de fenêtre (`useMediaQuery('(max-width: 992px)')`).
      - Bouton `.sidebar-toggle` avec infobulles dynamiques (« Masquer le menu latéral » / « Afficher le menu latéral »),
        attributs ARIA (`aria-expanded`, `aria-controls="sidebar"`).
    * `frontend/src/components/layout/Sidebar.jsx` :
      - Ingestion des props `open`, `collapsed` et `onClose`.
      - Bouton de repli direct `.sidebar-hide-toggle` dans `.sidebar-brand-top` avec chevron fonctionnel.
      - Préservation du déploiement lors des changements de page sur bureau.
    * `frontend/src/styles/sidebar.css` & `frontend/src/index.css` :
      - Transition fluide `0.3s cubic-bezier(0.16, 1, 0.3, 1)`.
      - Règle bureau : `.app-container.sidebar-collapsed .sidebar { transform: translateX(-100%) !important; }`.
      - Adaptation de la largeur : `.app-container.sidebar-collapsed .main-content { margin-left: 0 !important; width: 100% !important; }`.
      - Règle tiroir mobile : `.sidebar.show { transform: translateX(0) !important; }` avec fond d'occultation dépoli.

7.3 Validation par les Tests :
    * Suite `frontend/src/components/layout/Layout.test.jsx` créée et validée : **5/5 tests passés (100%)**.
    * Suite `frontend/src/components/layout/Sidebar.test.jsx` : **20/20 tests passés (100%)**.
